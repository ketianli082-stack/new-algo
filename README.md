# ALGOGENE 现货—永续合约基差套利研究

> 课程算法交易项目｜研究对象：BTC、ETH 现货与永续合约｜主要语言：中文

## 项目目标
基于 ALGOGENE 平台研究正基差收敛套利：等币数量买入现货、做空对应永续合约，在基差收敛时退出。项目既要测试策略能否盈利，也要依据课程的六个评分维度分析实现、风险、资金效率、回测及实盘可行性。

**当前基准：V8.1（paired-exit correction）**，重点改进双腿平仓前的报价同步校验，不应将其误写成提高信号收益的参数优化。当前尚未在本仓库获得可核查的回测结果；禁止将计划中的实验写为已经完成。

## 研究顺序
1. **建立可信基准**：核实合约规格、交易成本和账户 PnL 口径，固定 V8.1 代码及平台配置。
2. **回测及归因**：分别记录 2021–2025、2023–2025 和 2025，分析 BTC/ETH、交易退出原因与月份。
3. **稳健性及风险**：参数敏感性、手续费/滑点/资金费率压力测试、报价缺失及单腿异常。
4. **资金与实盘**：最低资金、资金利用率、杠杆、规模容量及真实交易场所可行性。
5. **形成报告**：每项结论均附代码版本、配置、回测 ID、数据表和图表。

已经移除旧教学算例的固定美元滑点/Funding/融资成本，改为**四腿百分比手续费、四腿百分比滑点、按历史结算时间逐次 Funding、按借款余额计算的年化融资利率**。当前没有提交真实历史 Funding 数据，测试 CSV 为人工样本；后续将下载并验证 BTC/ETH 各自真实历史结算数据，且不能将币安合约当作 ALGOGENE 四标的的同一合约。详见 [Funding 逐次历史结算说明](docs/BAS-001_百分比成本及历史均值.md)。

## 重要说明
- V8.1 使用 Bid/Ask，但**未额外编写百分比手续费、滑点及资金费率模型**；平台是否扣费需另行核对。
- 72 小时是**请求平仓**时间，并非保证完成平仓；双腿市场订单也不是原子成交。
- 建议时间角色：2021–2022 训练/探索、2023–2024 验证、2025 测试。但若 2025 已参与调参，不可再称严格独立样本外。
- 本仓库用于研究及课程报告，**不是无人值守的实盘交易系统**。
