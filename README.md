# ALGOGENE 现货—永续合约基差套利研究

> 课程算法交易项目｜研究对象：BTC、ETH 现货与永续合约｜主要语言：中文

## 项目目标
基于 ALGOGENE 平台研究正基差收敛套利：等币数量买入现货、做空对应永续合约，在基差收敛时退出。项目既要测试策略能否盈利，也要依据课程的六个评分维度分析实现、风险、资金效率、回测及实盘可行性。

**当前基准：V8.1（paired-exit correction）**，重点改进双腿平仓前的报价同步校验，不应将其误写成提高信号收益的参数优化。V8.1 仍为冻结对照基准；V8.2A/B 为成本感知候选版本。三组 2021–2025 回测工作流已成功完成，原始产物见下文；完整净成本和指标复核仍待完成。

## BAS-001 百分比成本与年度 Funding

成本按四腿成交名义额计入百分比手续费与滑点，买卖价差已在 Bid/Ask 中体现。Funding 主方案为**BTC、ETH 各自逐年度历史均值**，按实际持仓时间分段计算，跨年自动拆分；同时报告**不含 Funding 的收益**和**含年度 Funding 估算的收益**。年度历史均值目前尚未核实和填入，`config/funding_annual_rates_template.csv` 保持空白，人工测试值绝非真实历史数据。详见 [BAS-001 年度 Funding 方案](docs/BAS-001_年度平均Funding方案.md)。


## 重要说明
- V8.1 使用 Bid/Ask，但**未额外编写百分比手续费、滑点及资金费率模型**；平台是否扣费需另行核对。
- 72 小时是**请求平仓**时间，并非保证完成平仓；双腿市场订单也不是原子成交。
- 建议时间角色：2021–2022 训练/探索、2023–2024 验证、2025 测试。但若 2025 已参与调参，不可再称严格独立样本外。
- 本仓库用于研究及课程报告，**不是无人值守的实盘交易系统**。
