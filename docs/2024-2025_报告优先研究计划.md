# 2024–2025 报告优先研究计划（A → B → C）

生效日期：2026-11-22。此计划替代此前默认五年开发迭代路线；历史实验及证据保留。首要目标是完成老师六个章节、总计100分的课程报告，而非无限追逐平台Score。三人依次接手，不交叉开展策略修改。

## 1. 时间范围和统一配置
| 区间 | 角色 |
|---|---|
| 2024-01-01 至 2025-12-31 | 开发、优化、参数选择、风险与资金实验 |
| 2021–2023 | 冻结模型后历史跨期稳健性检验 |
| 2021–2025 | 最终长期综合表现 |
| 2026可得且未参与开发的数据 | 可选真正前向样本外验证 |

此前已研究2021–2025，因此2021–2023不能称严格未见样本外；向过去检验亦不等同于前向验证。记录数据预热和实际覆盖日期。统一H1、BTCUSD/BTCUSDM/ETHUSD/ETHUSDM、初始资金100万USD、杠杆1、无风险利率0、不设置固定TradeCost；成本情景每次成交手续费5bp及额外滑点1bp，Funding未知单列。所有实验启用统计模块，区分平台原生PnL、事后净收益估算与实际扣费后复利。

已有V8.1、V8.2A/B五年回测及V8.1统计验证。证据：[V8.1基准](https://github.com/ketianli082-stack/new-algo/actions/runs/44974549343)、[V8.2A/B](https://github.com/ketianli082-stack/new-algo/actions/runs/44972668942)、[统计验证](https://github.com/ketianli082-stack/new-algo/actions/runs/44977908701)。两年实验尚未启动。现有统计采用年末报价快照，并非正式结束回调；平台与内部PnL口径、Funding、时间加权敞口仍需完善。

| A08 | 下一小时可执行报价成交压力测试，同信号比较即时执行 | 必做 |
| A09/A10 | 冷却3h/1h | 优先 |
| A11 | 盈利退出冷却1h、止损6h | 优先 |

## 3. Phase B — 风险与资金管理（35分）
从A冻结提交创建成员B分支。负责风险管理20分、资金管理15分；在2024–2025区间做专项研究。
| 编号 | 任务 |
|---|---|
| B01–05 | 每次手续费/滑点bp：2/1、5/1基准、5/3、10/5、10/10；低中高必做，其余选做 |
| B06–08 | 无Funding、匹配历史Funding、不利Funding情景 |
| B09–14 | 单腿拒单、单腿延迟、行情中断6h/24h、基差快速扩大、连续止损 |
| B15–18 | 止损50/75/100bp及动态波动率止损；围绕A冻结参数 |
| B19–24 | 初始资金1千/1万/10万/100万/1000万/1亿USD；1万至1000万必做，两端选做 |
| B25–28 | 单组/总仓位20/40%、30/60%、40/80%、45/90%（末项选做） |
| B29–32 | 杠杆1/2/3/5倍（5倍选做） |

成本事后估算可复用成交名义额，改变成本决策才需重跑。Funding尽量使用实际结算数据，年度均值仅近似，不造数据。风险测试可用单元测试与事件回放，不必全部跑两年。必须说明最坏情形、管理措施、实际超额损失与人工恢复。同步订单非原子，72h仅退出请求。仓位研究区分实际敞口、保证金占用与平台杠杆；若杠杆不改变代码名义敞口，应报告该结果。规模测试无深度/冲击模型时不能证明实盘容量；最低投资额结合最小订单、数量步长、费用和缓冲计算。

交付/验收：
- [ ] 低中高成本、盈亏平衡成本及Funding分析
- [ ] 异常成交、中断、极端基差风险测试
- [ ] 止损、最大损失、风险预算及风险边界
- [ ] 资金规模、仓位、杠杆对照及最低/理想投资规模建议
- [ ] 最终资金风险配置及冻结SHA、证据
- [ ] 第3、4章正文及图表
重大安全缺陷先记录修复并重新验证A基准，随后冻结；C不继续调参。

## 4. Phase C — 最终评价与实盘研究（30分）
从B冻结提交创建成员C分支，负责回测表现20分、实盘预期10分和最终格式整合。
| 编号 | 区间/任务 |
|---|---|
| C01 | 最终模型2024–2025（可复用同配置结果） |
| C02 | 2021–2023历史跨期检验 |

绩效：平台Score及六项子分、毛净收益、累计与年化收益、波动率、Sharpe、Sortino、Calmar、最大回撤与持续时间、组合胜率、Profit Factor、交易频率、持仓分布、资金利用率、周转率、成本和Funding。区分按年初NAV归一的年度收益与独立重置资金的年度回测；按月平仓归因不是月度市值收益率。

报告图表：账户净值、回撤、月度收益热力图、年度收益率、BTC/ETH贡献、组合收益分布、成本敏感性、资金敞口变化。逐笔或分布数据缺失时先解决导出，不编造。A/B提供各自实验图表，C整合。

市场归因：2021牛市、2022 Terra/FTX、2023恢复、2024现货BTC ETF及减半、2025极端波动；这些是待核实候选事件，不等同于盈利因果。结合基差与成交数据检查最大10组亏损、退出原因、不同市场环境。实盘调研实际场所的地区可用性、现货/永续支持、成本、Funding、最小订单、保证金、深度、API、延迟、拒单及人工介入。解释有利/不利市场、频率、理想规模、杠杆必要性、假设合理性和局限。

## 5. 顺序分工、工期和停止规则
A（35分）策略研究 → B（35分）风险/资金 → C（30分）跨期回测/实盘/整合。C额外承担报告格式及综合图表以平衡工作量。分支顺序 main历史基准 → lkt(A) → B分支 → C分支 → 审核合并main；后续分支从上阶段冻结SHA建立。每人负责自己实验、分析、图表与正文。
计划工期：紧凑6天（每人2天）、标准9天（每人3天）、完整版12天（每人4天），按课程截止和平台排队调整，非回测完成时间承诺。优先完成必做任务，再做选做；不为微小Score增益延迟写报告。若发现数据/执行缺陷，先修复；无法验证时如实披露，避免无限迭代。
