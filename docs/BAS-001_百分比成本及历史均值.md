# BAS-001 成本核算与 Funding 方案（索引）

**当前采用：BTC、ETH 分别按年度历史平均 Funding Rate 估算，跨年按持仓小时拆分。**

详细方案、输入格式、数据限制请看：[BAS-001 年度平均 Funding 方案](BAS-001_年度平均Funding方案.md)。

原始逐次 Funding 计算代码仍保留为备选研究工具 `tools/historical_funding.py`，但 BAS-001 主模型已改为 `tools/annual_funding.py`。

年度历史平均数据尚未经过核验，模板为空，不允许自动补零。人工测试数据不得被当成真实历史。实际 ALGOGENE 账户 NAV 尚未加入该离线估算项。

交易手续费及滑点仍按每条成交腿的名义金额比例计算；Bid/Ask 已计入毛 PnL；融资成本按真实借入本金和年化借款利率计算。若平台已经扣费，避免重复扣除。
