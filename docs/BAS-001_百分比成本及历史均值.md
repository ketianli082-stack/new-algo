## 所需原始历史文件
CSV 列：`symbol,funding_time_utc,funding_rate,mark_price`

- `symbol`: 如 BTCUSDT 或 ETHUSDT，必须与实际数据文件一致
- `funding_time_utc`: ISO UTC 时间，如 `2025-01-01T08:00:00+00:00`
- `funding_rate`: 当次费率小数，例如 `0.0001` = 0.01%（不是年化）
- `mark_price`: 结算时用于名义金额计算的标记价格

**计算式：** 对永续空头，`Funding_USD = Σ(持仓数量 × 结算标记价格 × 当次费率)`，只计入持仓期间的结算记录。正数为收款、负数为付款。请根据真实成交与结算的先后关系处理恰好同秒的边界。

**重要限制：** 公式只适用于 USD 线性等币数合约；币本位反向合约的币数量、合约面额、结算货币均可能不同，需要按真实合约规则转换后使用。历史 Funding 缺失、错误或不完整会使净收益失真；脚本只校验所选区间是否存在记录及是否重复，并不保证所有应有结算点都齐全，下载后须核对完整性。

## 获取真实历史 Funding（公开代理数据）
运行：
```bash
python -m tools.download_historical_funding \
  --symbols BTCUSDT ETHUSDT \
  --start 2021-01-01T00:00:00+00:00 \
  --end 2026-01-01T00:00:00+00:00 \
  --output data/binance_usdm_funding_2021_2025.csv
```
该脚本按 API 提供的分页逐条获取实际费率和标记价格，保留结算时点。若 API 网络受限、限流、时间段不覆盖或历史产品不足，不能填补虚构数据。**本仓库目前尚未执行该全量下载。**

数据接口（Binance 官方）：
- USDⓈ-M: https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Get-Funding-Rate-History
- COIN-M: https://developers.binance.com/docs/derivatives/coin-margined-futures/market-data/rest-api/Get-Funding-Rate-History-of-Perpetual-Futures

由于 Binance BTCUSDT/ETHUSDT 与 ALGOGENE BTCUSDM/ETHUSDM 不一定为同一种合约，先将 Binance 下载作为**外部代理研究**；真实经济收益必须核实后使用与回测品种一致的数据。

## 成本的其余参数
- 手续费按每一腿成交名义额的百分比
- 额外滑点按每一腿成交名义额的百分比；不能与成交价中已包含的滑点重复
- 融资成本按实际借款额 × 年化利率 × 真实持仓时长计算；无借款时为零
- 买卖价差在 Bid/Ask 成交价中已经体现，不额外重复扣除

## 正式实验操作
1. 核对真实合约类型、匹配真实 Funding 来源，确认资金费结算周期（可能变化）。
2. 保存原始结算数据及查询参数、来源、下载日期、SHA；按 BTC/ETH 分别验证时间覆盖。
3. 导入 BAS-001 逐笔成交起止时刻、仓位数量；不允许拿历史平均代替逐次记录。
4. 将 Funding 逐笔记录和总和与账户净值口径做勾稽。若平台已记入 Funding，则不再离线重复加。
5. 只有完整实际记录才可报告“历史 Funding 净收益”。其他情况标注为外部代理情景或数据不足。
