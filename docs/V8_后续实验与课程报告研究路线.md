### 执行摘要
理论：Basis Trading、Mean Reversion、Law of One Price、Cash-and-Carry、Market Neutrality、Funding Rate Mechanism。永续没有固定到期日，不能称为确定收敛的无风险套利。解释 BTC/ETH 选取、H1 bid/ask、NAV、基差与 Z-score 输入。

### 实现细节：单变量敏感性
| 参数 | 基准 | 候选 |
|---|---|---|
| 窗口 | 168h | 72h、336h |
| 入场 Z | 2 | 1.5、2.5 |
| 最低入场基差 | 30bp | 20、40bp |
| 最低毛收益空间 | 20bp | 10、30bp |
| 止损 | 75bp | 50、100bp |
| 最大持仓 | 72h | 24、48、120h |
| 冷却 | 6h | 1、3h、按退出原因 |
| 成本仓位 | V8.2B | 通过过滤后最低仓位50%、75% |

建议2021–2023开发、2024验证、2025测试的时间分层仅作回顾性分析：五年数据已经参与策略选择，不能称2025为真正未见样本。冻结模型后使用后续未参与开发的数据，或严格滚动前推，并披露选择偏差。

### 风险管理：压力测试
| ID | 实验 | 目的 |
|---|---|---|
| R01 | 原报价成交 | 对照 |
| R02 | 下一小时可执行报价成交 | 检验信号与成交时序 |
| R03 | 每次成交额外滑点1/3/5/10bp | 流动性及成本风险 |
| R04 | 单腿拒单、成交延迟 | 异常恢复、未对冲敞口 |
| R05 | 行情中断6/24h | 同步退出及超期持仓 |
| R06 | 基差持续扩大 | 止损与尾部损失 |
| R07 | 不利资金费率 | 持仓成本压力 |

风险因素还包括保证金/强平、均值回归失效、数据质量、规模冲击与操作风险。72h是退出请求期限而非保证平仓；协调提交不是原子成交。计划止损不保证实际最大亏损。

仓位上限实验：C07 单组20%/总40%、C08 30%/60%、C09 40%/80%、C10 45%/90%。杠杆实验 L01–L04：1/2/3/5倍。须区分平台保证金杠杆与代码实际名义敞口；只修改平台杠杆可能不改变仓位。没有市场深度与冲击模型的规模回测不能证明实盘容量。最低资金应结合实际最小订单、合约数量步长、费用与流动性缓冲确定。

### 回测表现与数据交付
- 净值曲线、回撤曲线、60个月月度收益热力图、年度收益率、单组收益分布、成本敏感性曲线。
- 按 BTC/ETH、收敛/止损/超时退出、持仓时长、牛熊震荡市场归因。
- 最大10笔亏损、平均及分位数持仓时间、盈利月份占比、净敞口、资金利用率、空仓时间、交易频率、周转率。
- 对比 Score及六项分数、PnL、收益率、Sharpe、Sortino、最大回撤、胜率、Profit Factor、交易次数、扣费后收益。
- 目前 API 成交与日志返回存在数量限制，优先实现完整导出或策略内部累计结构化审计，不能用截断成交推算完整成本。手续费按逐腿实际成交名义额核算，滑点与买卖价差避免重复计入；资金费率独立统计，缺失时报告为未知或情景假设。基于毛收益的成本后重建不等于真实扣费后复利回测。
- 年度利润比较应同时展示按当年期初净值归一化的收益率，避免复利规模混淆。

### 实盘交易预期
调研实际交易所的现货/线性永续、地区可用性、费率等级、资金费率、最小成交量、保证金、API限频、深度、延迟与拒单。候选 Binance、OKX、Bybit（具体规则待核实）。说明有利/不利市场、日/月/年交易频率、理想规模、杠杆必要性，以及无法确认成交时需人工介入。不能宣称无人值守实盘已经验证。

## 3. 实验优先级与执行顺序
1. P0：验证成交价格及时间同步、下一小时成交压力测试、完整交易成本统计；异常高收益须核实数据和成交口径。
2. P1：V8.3A 3h冷却、V8.3B 1h冷却、V8.3C 按退出原因冷却；研究止损后信号恢复及重新入场。V8.4 温和成本仓位；V8.5 成本感知止盈；V8.6 动态止损；V8.7 动态持仓时间。保留安全退出，不因成本止盈而阻止止损或超时退出。
3. P2：参数敏感性、资金规模、仓位上限和杠杆实验。
4. P3：最终模型冻结与前推验证、风险压力测试汇总、交易归因、文献和实盘研究、报告制图。

默认新一轮对照使用2021–2025且一次改变一个机制；必要时采用独立子区间或后续数据验证。以 V8.2A 作为候选开发基础，保留 V8.1 和 V8.2B；最终选择须依实际结果。不得为追求 Activeness 制造无经济意义的交易。所有实验先写配置、假设、代码SHA与验收标准；保留原始结果、失败记录与结论。排队运行，避免重复提交。此文档不触发新的回测。
